# Mindpath AI

A student-friendly learning website with practice questions, timed mocks, 30-day English practice, a multi-task study assistant, and a broad question-paper catalogue.

## Question papers
The catalogue covers CBSE, Maharashtra SSC/HSC, ICSE/ISC and many major state boards. Paper cards link to official board portals rather than copying third-party copyrighted papers.

## AI assistant
The built-in assistant works without an API key for common school-study tasks. For true cloud/LLM responses, add a secure backend/API endpoint; do not put a secret API key directly in this GitHub Pages frontend.
